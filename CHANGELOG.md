# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog.

## [1.0.0] - 2026-03-23

### Added
- Initial release of the GA4 Custom Task Interceptor.
- Core interceptor for patching `window.fetch` and processing GA4 hits.
- `piiScrubberTask` for automatically redacting emails and phone numbers.
- `mapClientIdTask` for capturing the GA4 Client ID as a custom parameter.
- Documentation: README, USER_GUIDE, CHANGELOG, and COVER_PAGE.
